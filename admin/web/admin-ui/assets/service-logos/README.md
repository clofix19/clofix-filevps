# Service brand assets

These local assets identify their corresponding upstream projects. Exact source
URLs are recorded in `sources.json`; no third-party image requests are made by the
Library UI. Most SVGs come from the Devicon project (see `DEVICON-LICENSE`). Joomla
and OWASP marks come from Simple Icons; the remaining marks come from official
project sites or repositories. Original brand ownership remains with each project.

Build tools uses the GCC project mark; VS Code Web uses the VS Code mark. Joomla
and OWASP monochrome SVGs use a dark fill for readability on the neutral badge.
