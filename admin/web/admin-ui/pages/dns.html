DNS Service

Automatic DNS records for FileVPS, load balancers, CKS clusters, databases, managed apps and workers. Manual records can be added to the same zone.

Overview

Automatic records appear when a VPS, load balancer, CKS cluster, database, app or worker is created. CKS-attached load balancers also get {service}.{cluster}.cks.{zone} aliases. The controller answers this zone on 127.0.0.1:53 and HTTP names on 127.0.0.1:80. Query with dig @127.0.0.1 web.clofix.internal. Per-name /etc/hosts entries are not required. On this Mac, one resolver file /etc/resolver/clofix.internal containing nameserver 127.0.0.1 lets browsers open http://web.clofix.internal/.

Zone settings

Names are created as {id}.{service}.{zone}. A publish address is used only when an ALB has no allocated IP.

Records

Select a FileVPS, load balancer, CKS cluster, database, app or worker to point a name at that service. CKS Service lists the cluster plus Kubernetes Services and Ingresses. Port lists every mapped HTTP, HTTPS, lab, NodePort and guest port. Port is stored and exported as an SRV record.

Certificates

Point the domain A/AAAA at this controller, open TCP 80 for HTTP-01, choose an ALB or managed app, enter the hostname, then request a certificate. New domains are attached to the resource automatically. Set CLOFIX_ACME_EMAIL on the controller. TLS is served on :443.

Pick an existing hostname or type a new one to attach.

Zone file

Download a BIND-style export. The live zone is also served on UDP/TCP 53 at 127.0.0.1.
