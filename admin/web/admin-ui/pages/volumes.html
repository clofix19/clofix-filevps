Create volume

Volumes are created on one worker and attach only to VPSs on that worker.

A limit creates a capped ext4 filesystem. Leave blank for unlimited storage. The worker must support loop devices and ext4.

Edit volume

Change the display name without changing its data or attachment. A hard size limit is chosen at creation.

Attach volume

Select a ready volume; VPSs on its worker appear automatically. A running VPS restarts to apply the mount.

Mounted contents remain writable while Protection Mode makes the guest root read-only.

Volume inventory

Deleting a volume permanently removes its worker data. Detaching keeps it available to reattach.

Volume Explorer

Browse, edit, upload, and manage files in ready or attached volumes. File size limit: 4 MB per upload or download.

If you mount an empty volume at /var/www/html, it covers the image’s existing web files. Nginx may return 403 until you upload a readable index.html (or configure a different index page) here.
