Recovery and restore

VPS backups

Worker-local snapshots of a stopped VPS writable root filesystem. Restore a backup as a new VPS with its own SSH key and resource limits.

Recovery

Run backup as a new VPS

Choose the backup and set the new VPS resources and SSH key.
Backup scope

Snapshot size is the compressed archive size. Disk allocation is placement accounting and does not enforce a disk quota. Persistent volumes and S3 mounts are not included. Create backups only while the VPS is stopped; restore currently requires the original worker and its cached base image.
