EKS-style workload console. Create from the form, apply YAML, then scale, restart or delete. Secrets store names only in inventory.

Select a pod to request logs.

CloFix attach

Use existing CloFix load balancers, FileVPS, volumes, EFS and S3 as Kubernetes Services, PVCs and Secrets. FileVPS is a companion backend, not a kubelet node.

VPS groups

A VPS group is the set of CKS worker nodes that execute pods, Services and other workloads. Nodes are sized like FileVPS (CPU, RAM, disk) and run kubelet on dedicated CKS workers. FileVPS guests cannot run kubelet.

Helm

Allowlisted chart references only. The worker uses helm when installed, otherwise records a fake release for labs.

Storage, ingress, RBAC, HPA

Install the CKS local StorageClass and nginx IngressClass, or apply your own manifests. FileVPS guests still cannot run CSI node plugins.

HA, backups and upgrades

Production-ready is withheld until FileVPS kubelet validation passes and live kubeadm e2e is opted in.
