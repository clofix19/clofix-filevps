Storage

EFS

One named share many VPS can mount, including backends on other workers. Files live on CloFix S3; each worker mounts the prefix once and bind-mounts it into attached guests.

Volumes stay 1:1 on a single worker. For load-balanced web roots, attach the same share to each member at /var/www/html. Creating a load balancer does not create EFS automatically.
