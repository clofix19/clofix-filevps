Resources

        
RAM, CPU, and swap limits apply after the worker restarts the VPS. Disk is a placement allocation; hard disk quotas are not enforced.

        

        

      

      

        
Access

        
VPS Login Console
SSH login
Connect securely from your Mac Terminal while the VPS is running.

        ssh -p PORT root@localhost
        
The VPS uses the private key matching the public key you added when creating it. For a non-default key, add -i ~/.ssh/your-private-key.

        

        
Root password
PAM password login is off unless enabled at create or here.

      

      

        
Services

        
Per-service RAM uses PSS, which apportions shared process pages instead of counting them repeatedly. Older kernels fall back to RSS. VPS RAM also includes filesystem cache and kernel memory, so service totals may not equal VPS usage. ZRAM is shared at worker level.

CloFix Security
Protection Mode
Protected root filesystem
Enabled

        
When enabled, the guest root filesystem is read-only. /run, /tmp, /var/log, and APT indexes/cache use temporary storage and are cleared on restart. apt update can refresh temporary indexes; package installation and persistent changes require disabling Protection Mode. Processes and network access remain active.

        

        

        

        
SSH Login Block
SSH login is allowed
Disabled
Blocks new SSH logins to this VPS. Existing sessions may remain connected until closed. Changing this setting restarts a running VPS to apply the SSH server policy.

        
VPS Delete Protection
Deletion requires this protection to be disabled
Disabled
Prevents VPS deletion through the CloFix admin API. Disable this setting here before deleting the VPS.

        
SSH Key-Only
Password authentication policy
Disabled
When enabled, root password login is turned off and only the installed SSH public key can authenticate. An SSH authorized key must already be present on this VPS.

Off
