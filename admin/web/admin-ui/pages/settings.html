General Settings

New VPS defaults are saved in this browser and applied to future creations only.

Pricing & Plans

Create and edit catalog prices for VPS, Managed Database, Object Storage, Backup, Network, Load Balancer, CKS and License plans. Changing a price does not rewrite an existing customer’s active subscription. Set when the new catalog price becomes effective.

Required when editing rates or allocations. Active subscriptions keep their snapshot price.

Resource Pricing

Standard and Low cost unit prices for CPU, RAM, disk, CKS, load balancers, backup, volume, EFS, S3 and applications. CKS is the CloFix Kubernetes Service control-plane unit; node CPU/RAM/disk use the rows above. Attached CloFix load balancers bill on the Load balancer row. Hourly rates update Due bill every minute. A 5 or 10 minute run is billed for those minutes even if the resource or port is deleted. Zero and disabled means the unit is not billed yet. Stopped VPS and databases use the disk/volume rate only. These values do not change active subscriptions.

Discounts & Promotions

Promo codes stored on the controller. They are not applied to existing invoices until a billing charge uses them.

Payment Gateway Settings

Store provider credentials on the controller. Card charges are not processed in this version. Use Billing & Payments to record a manual payment.

The secret is stored on the controller and never returned to the browser. Leave blank to keep the saved key.

Currency & Tax Settings

Bookkeeping FX for invoice USD/BDT columns. New invoices snapshot this rate.

Billing Notifications

These flags are stored only. No billing mailer is connected yet.

Notification channels

Send Health Checks and Log Service alerts to Slack, Google Chat, Discord, Microsoft Teams or a JSON webhook. Configure checks in Health Checks and keyword/level rules in Log Service.

The URL is stored on the controller and never returned to the browser. Leave blank when editing to keep it.

NLB network settings

IPs must be assigned/routed to the controller. Local host testing example: 127.0.0.2-127.0.0.10. This is not a public IP range.

Update an existing load balancer

Choose a load balancer to see its current IP.

Uses a unique IP from the saved pool. Existing backend VPS instances are retained; their next TCP health check refreshes readiness.

License configuration

Connect to the CloFix company license server. Plans and license issuance are managed separately by CloFix.

Use the CFL- key shown when issued, not the lic- ID. Leave blank to keep the saved key.

Resource usage and quotas

Validation runs every 5 minutes after configuration. All resource creation and growth follow the validated license quotas. Unspecified optional limits do not permit allocations. Existing resources are not automatically deleted.
