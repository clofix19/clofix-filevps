New VPS defaults

Saved in this browser and applied to future creations only.

Notification channels

Send down and recovery alerts to Slack or a JSON webhook. Configure checks in Health Checks.

The URL is stored on the controller and never returned to the browser. Leave blank when editing to keep it. Slack: create an incoming webhook.

NLB network settings

IPs must be assigned/routed to the controller. Local host testing example: 127.0.0.2-127.0.0.10. This is not a public IP range.

Update an existing load balancer

Choose a load balancer to see its current IP.

Uses a unique IP from the saved pool. Existing backend VPS instances are retained; their next TCP health check refreshes readiness.

License configuration

Connect to the CloFix company license server. Plans and license issuance are managed separately by CloFix.

Use the CFL- key shown when issued, not the lic- ID. Leave blank to keep the saved key.

Resource usage and quotas

Validation runs every 5 minutes after configuration. All resource creation and growth follow the validated license quotas. Unspecified optional limits do not permit allocations. Existing resources are not automatically deleted.
