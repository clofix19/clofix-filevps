Per-VPS security controls

Manage a VPS to change its individual settings. SSH policy changes restart a running VPS.

◉
Protection Mode

Mounts the persistent guest root read-only. It does not block running processes or network traffic.

⌁
SSH Login Block

Blocks new SSH connections when enabled. Existing SSH sessions may remain until disconnected.

▣
VPS Delete Protection

Prevents deletion through CloFix APIs and worker operations. Host administrators with direct storage access can still remove data.

⬡
OWASP CRS WAF

Inspects HTTP/HTTPS requests served by this VPS through Nginx. Direct SSH, database ports, and traffic bypassing Nginx are outside its scope.

Custom port forwards

Additional guest ports exposed on host ports. Default SSH, HTTP, and HTTPS mappings are managed by CloFix.

Review each forwarded port and remove mappings that are not needed. A port forward exposes that guest service; the WAF only protects HTTP/HTTPS requests routed through Nginx.
