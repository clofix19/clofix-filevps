CloFix runtime protections

Controls enforced by the worker for guest processes.

◉
Protection Mode

Read-only persistent guest root by default; writable temporary paths are cleared at restart.

⬡
Linux namespaces

Guest processes use separate mount, PID, UTS, IPC, and network namespaces.

▤
Resource limits

CPU, memory, swap, and process limits are applied per VPS using cgroup v2.

⌘
Seccomp filter

The worker installs a syscall filter for guest init processes.

Protection Mode does not block network access or prevent a running process from reading data. Use port forwards only for services you intend to reach.

VPS protection

Mode changes restart a running VPS before taking effect.

Custom port forwards

Extra guest ports forwarded to host ports. Default SSH, HTTP, and HTTPS mappings are managed by CloFix.
