Guide
What each Security Center control does. Click a card to open that panel in the left list. Catalog statuses: live, partial, planned, satisfied_by_ro. Full list #1–72 + mgmt is under Advanced Protection.

            

              ◉
Protection Mode
Mounts the persistent guest root read-only (#1). Satisfies several FileVPS write locks via satisfied_by_ro. Does not stop running processes or filter network. Orthogonal to Security Modes.
Open VPS controls →

              ⌁
SSH Login Block
Blocks new SSH connections (#16). Existing sessions may remain until disconnect. Temporary unlock can clear this for a TTL.
Open VPS controls →

              ◇
SSH key-only
Disables password authentication (#17). Prefer with an authorized key. Root SSH uses prohibit-password when key-only is on (#19 partial).
Open FileVPS tab →

              ▣
VPS / volume delete protection
VPS flag blocks delete via CloFix APIs and workers. Volume delete protection (#66) blocks volume removal the same way. Host storage admins can still wipe disks.
Open Storage tab →

              ⬡
OWASP CRS WAF
ModSecurity CRS on guest Nginx (#36). SQLi / XSS / RCE / LFI (#37–40) are CRS categories, not separate engines. SSH, DB ports, and traffic that bypasses Nginx are out of scope.
Open VPS controls →

              ▤
Firewall and exposure
Inbound CIDR allow/deny on the Firewall page (#26, #20 SSH allowlist). Exposure scanner flags published / custom forwards (#28). Egress filter is planned (#27). Suggest-deny is approval-gated (#30).
Open Network tab →

              ⊗
Network quarantine
Applies tpl-quarantine (Protection + SSH block + delete protection) and restricts inbound firewall (#34). Snapshot saved for rollback. AutoPilot approval mode may require a queue entry first.
Open Unlock & quarantine tab →

              ☰
Security Modes
Policy templates (e.g. tpl-hardened) dry-run / apply supported controls (#100, #106, #110). Separate from Protection Mode. Bindings + scheduler tick re-apply on schedule (#102).
Open Modes →

              ◷
Temporary unlock
Time-boxed clear of Protection Mode or SSH Login Block (#21, #103). Scheduler tick restores expired unlocks and applies due mode bindings.
Open Unlock & quarantine tab →

              ✓
Approvals and rollback
Queue for protection-off, mode apply, quarantine, firewall deny, destructive DB (#25, #104). Rollback restores the last control snapshot for a VPS (#107).
Open Approvals tab →

              ◎
Security score
Starts at 100. Subtracts capped deltas for Protection Mode off, missing WAF, inactive workers, lab user_ns=false, and recent log alerts. Findings ledger lists each delta.
Open Score →

              ⌖
Detection and FIM
Log alerts and auth failures surface as detections (#18, #23 partial). FIM baselines store worker path hashes (#6, #15, #54). Refresh does not wipe existing baselines.
Open Detection →

              ⚙
Worker posture
User NS, seccomp, caps, cgroups (#48–57). Drain sets maintenance lock and blocks new placement (#58). AppArmor/SELinux per guest remains planned (#51).
Open Worker tab →

              ◫
Databases and CKS
DB score from TLS CA, public exposure, encrypted backups (#60–64). Package CVE feeds planned. CKS score from readiness. Not a certification claim.
Open Vulns / DB / CKS →

              ▶
AutoPilot
Monitor / Recommend / Approval / Auto Protect / Emergency Lockdown. Never auto-shutdown production on low-confidence detections. Compliance export maps CIS/ISO/SOC2 controls (#111).
Open AutoPilot →

              ⎘
Audit and alerts
Controller mutations in Audit (#108). Open log alert-events feed Score and Alerts; manage rules on Logs and channels on Health Checks (#109).
Open Audit →
