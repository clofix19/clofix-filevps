Backend VPS instances

How it works

Each balancer is the replica pool. It creates and owns backend VPS instances between the minimum and maximum, like pods. The selected backup must run your application on the configured backend port. NLB forwards TCP without terminating TLS and scales on CPU only. ALB can also scale on request hits. The public endpoint forwards application traffic without a controller login.

Save an EFS share ID and guest path on the balancer. Every backend VPS — the first members and later scale-out — mounts that share at the path you set (default /var/www/html). The balancer does not create the share; pick one from Storage → EFS.
