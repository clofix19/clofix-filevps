Networking

VPC

Private IPv4 blocks on the FileVPS bridge 10.231.0.0/16. The default block cannot be deleted. Extra blocks must be non-overlapping subnets of that range.

OverviewDefault block and extra subnets IP blocksCreate, edit and delete extra VPCs

Overview

New FileVPS, managed app, and database resources take an address from the default VPC unless another block is selected. Guest traffic still uses gateway 10.231.0.1. Managed apps stay on 10.231.128.0/24.

IP blocks

Name and CIDR for extra VPCs, for example 10.231.20.0/24. The default CIDR cannot be changed. Delete is blocked while the block still has VPS, database, or app addresses.
